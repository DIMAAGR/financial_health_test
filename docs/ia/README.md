# IA no Processo

Esta pasta centraliza o uso de IA no projeto com três objetivos:

- explicitar regras de uso
- registrar decisões com evidências
- acumular aprendizados para evitar repetição de erro

## Arquivos

- Regras de uso: [rules.md](./rules.md)
- Log de prompts e resultados: [prompt_log.md](./prompt_log.md)
- Memória de erros e melhorias: [learnings.md](./learnings.md)

## Princípio

IA é ferramenta de aceleração e exploração.
A responsabilidade por decisão, validação e qualidade final é humana.
